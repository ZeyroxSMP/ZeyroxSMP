STRAIGHT ANSWERS.

The basics for getting started. For server-specific settings that are not confirmed here, ask the owner or staff.

What's the server IP?

velofun.mcsh.io. Copy it from the Join page and paste it into Minecraft's Server Address field.

Which Minecraft version?

The supported version has not been confirmed on this website. Ask the server owner if you get a version error.

Can I join from Bedrock?

Bedrock support is not confirmed. Ask the owner whether the server supports Bedrock or Java only.

Is PvP allowed?

Check the server's current PvP settings and staff rules before fighting or raiding another player.

Is there an economy or shop?

This site does not confirm any economy plugin, player shop, or currency commands. Ask staff which features are enabled.

What if I see cheating?

Do not start an argument. Save useful evidence if safe to do so and report it to server staff.

Can I appeal a punishment?

Contact the server owner or staff politely and explain what happened. Appeals should be reviewed fairly.

How do I copy the IP?

Press the Copy button on the Home or Join page. If it does not work, select and copy the address manually.

Where are official updates?

Use the server's official community channel if the owner has one. No Discord or social link is added here until confirmed.
